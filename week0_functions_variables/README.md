> The very first steps into Python: reading input, printing output, using variables, and writing your first functions. 🌱

---

## 📂 Problems in this folder

| Script | Problem | 💡 Summary |
|---|---|---|
| `indoor.py` | 🔉 Indoor Voice | Converts shouted (uppercase) text into a calm, lowercase "indoor voice" |
| `playback.py` | ⏯️ Playback Speed | Replaces spaces with `...` to simulate slowed-down audio playback |
| `faces.py` | 🙂 Making Faces | Turns `:)` and `:(` into emoji faces |
| `einstein.py` | ⚛️ Einstein | Calculates energy from mass using `E = mc²` |
| `tip_calculator.py` | 🧾 Tip Calculator | Computes how much tip to leave based on the bill and percentage |

---

## ▶️ How to run

```bash
python indoor.py
python playback.py
python faces.py
python einstein.py
python tip_calculator.py
```

## 🧠 Concepts practiced

- `input()` / `print()`
- String methods (`.lower()`, `.replace()`, `.isupper()`)
- Basic arithmetic operators
- Defining and calling functions
- The `if __name__ == "__main__":` idiom
