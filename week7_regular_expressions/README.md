## 🧠 Concepts practiced

- `re.fullmatch()`, `re.search()`, `re.findall()`
- Capture groups and `match.group()`
- Word boundaries (`\b`) and character classes
- Designing patterns that reject invalid edge cases (not just accept valid ones)
