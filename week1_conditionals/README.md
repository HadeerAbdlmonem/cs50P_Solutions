## 📂 Problems in this folder

| Script | Problem | 💡 Summary |
|---|---|---|
| `deep.py` | 🌌 Deep Thought | Checks whether the answer given is "42" in any accepted form |
| `extensions.py` | 📁 File Extensions | Guesses a file's MIME type from its extension |
| `meal.py` | 🍽️ Meal Time | Decides whether a given time falls into breakfast, lunch, or dinner |

> ℹ️ **Note:** `bank_.py` ("Home Federal Savings Bank") also belongs to this week conceptually, but since a `test_bank_.py` was written for it, it's grouped together with its tests in **[Week 5 — Unit Tests](../week5_unit_tests)** instead of being duplicated here.

## ▶️ How to run

```bash
python deep.py
python extensions.py
python meal.py
```

## 🧠 Concepts practiced

- `if` / `elif` / `else`
- Boolean logic (`and`, `or`, `not`)
- Comparison operators
- String parsing with `.split()`
