## 📂 Problems in this folder

| Script | Problem | 💡 Summary | 📦 Library |
|---|---|---|---|
| `emojize.py` | 😀 Emojize | Converts emoji shortcodes into emoji characters | `emoji` |
| `figlet.py` | 🔤 Frank, Ian, and Glen's Letters | Renders text in ASCII-art fonts | `pyfiglet` |
| `adieu.py` | 👋 Adieu, Adieu | Bids a proper farewell to a list of names | — |
| `game.py` | 🎯 Guessing Game | A number-guessing game with adjustable difficulty | `random` |
| `professor.py` | ➕ Little Professor | Generates addition problems at three difficulty levels | `random` |
| `bitcoin.py` | ₿ Bitcoin Price Index | Converts bitcoin to USD using a live exchange-rate API | `requests` |

---

## ▶️ How to run

```bash
pip install -r ../requirements.txt
python emojize.py
python figlet.py
python adieu.py
python game.py
python professor.py
python bitcoin.py 0.5
```

## 🧠 Concepts practiced

- Installing and importing third-party packages with `pip`
- Making HTTP requests (`requests`)
- Working with the `random` module
- Command-line arguments (`sys.argv`)
