---

## 📂 Projects in this folder

| Script | 💡 Summary | 📦 Library |
|---|---|---|
| `app.py` | 🖩 A GUI calculator (add, subtract, multiply, divide) | `tkinter` |
| `Text_to_Speech.py` | 🔊 A GUI that reads entered text aloud | `tkinter`, `pyttsx3` |

## 📊 Leftover data files

| File | Note |
|---|---|
| `mfa.csv` | Museum-of-Fine-Arts-style sample dataset — not consumed by any script in this repository |
| `votes.csv` | Sample voting/titles dataset — not consumed by any script in this repository |

These two CSVs don't correspond to any script here; they're kept for reference in case they were meant for a future exercise. 🗃️

---

## ▶️ How to run

```bash
pip install pyttsx3
python app.py
python Text_to_Speech.py
```

## 🧠 Concepts practiced

- Building GUIs with `tkinter` (`Label`, `Entry`, `Button`)
- Event-driven programming (`command=...` callbacks)
- Text-to-speech synthesis with `pyttsx3`
