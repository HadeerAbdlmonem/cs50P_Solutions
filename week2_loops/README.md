## 📂 Problems in this folder

| Script | Problem | 💡 Summary |
|---|---|---|
| `camel.py` | 🐫 camelCase | Converts `camelCase` into `snake_case` |
| `coke.py` | 🥤 Coke Machine | Simulates a vending machine accepting nickels, dimes, and quarters |
| `twttr.py` | 🐦 Just setting up my twttr | Removes vowels from text, old-Twitter-handle style |
| `nutrition.py` | 🍎 Nutrition Facts | Looks up the calorie count of a fruit |

> ℹ️ **Note:** `plates.py` ("Vanity Plates") also belongs to this week conceptually, but since a `test_plates.py` was written for it, it's grouped together with its tests in **[Week 5 — Unit Tests](../week5_unit_tests)** instead of being duplicated here.

## ▶️ How to run

```bash
python camel.py

python nutrition.py
```

- `for` loops and `while` loops
- Loop control (`break`, `continue`)
- Iterating over strings and dictionaries
- `enumerate()`
